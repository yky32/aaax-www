# aaax-www

Product site for **[AAAX](https://github.com/yky32/aaax)**.

### Live

**https://aaax-www.vercel.app/**

Astro 7 + Tailwind 4 · Vercel (`yky32s-projects/aaax-www`) · auto-deploy from `main`.

## Dev

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Output: `dist/`.
